Tutorials
=========

.. list-table::
   :header-rows: 1
   :widths: 25 55 20

   * - Tutorial
     - Description
     - Notebook
   * - Introduction to this library
     - An overview of the features offered by `pyvisim`, to get you familiar with 
       its **API**.
     - `Getting Started <https://github.com/MechaCritter/Python-Visual-Similarity-Examples/blob/master/notebooks/getting_started.ipynb>`_
   * - Image search
     - This is the most interesting tutorial of this library, so I recommend that you
       definitely check this out 😊

       Build an image gallery, index the embeddings and retrieve the most
       similar images for a query using different enhancement tricks such as
       ``reranking`` and ``query expansion``.
     - `Image Search <https://github.com/MechaCritter/Python-Visual-Similarity-Examples/blob/master/notebooks/image_search.ipynb>`_
    * - Image Clustering
      - Show the clustering performance via metrics like `RI`, `ARI`, `NMI`
        using embeddings generated by the ``Clip Embedder``.
      - `Clustering Images <https://github.com/MechaCritter/Python-Visual-Similarity-Examples/blob/master/notebooks/clustering_images_clip.ipynb>`_
   * - Train a Siamese network
     - Train a Siamese network, one of the earlier concepts of how to use neural networks for 
       image similarity tasks. 
     - `Siamese Network <https://github.com/MechaCritter/Python-Visual-Similarity-Examples/blob/master/notebooks/siamese_network.ipynb>`_
   * - Train a Triplet network
     - Train a triplet network with anchor, positive and negative samples to
       learn an embedding space for retrieval.
     - `Triplet Network <https://github.com/MechaCritter/Python-Visual-Similarity-Examples/blob/master/notebooks/triplet_network.ipynb>`_
   * - Performance accuracy of retrieval pipeline
     - Evaluation of the **mean Average Precision** (mAP) of the retrieval pipeline, 
       composing the ``Clip Embedder`` as the embedding model.
     - `Retrieval Evaluation <https://github.com/MechaCritter/Python-Visual-Similarity-Examples/blob/master/notebooks/m_ap_and_top_k_accuracy.ipynb>`_
   * - VLAD and Fisher Vector
     - Learn how ``VLAD`` and ``Fisher Vector``, previously state-of-the-art methods for 
       image retrieval, work.
     - `VLAD and Fisher Vectors <https://github.com/MechaCritter/Python-Visual-Similarity-Examples/blob/master/notebooks/vlad_and_fisher_with_resnet18_deep_features.ipynb>`_

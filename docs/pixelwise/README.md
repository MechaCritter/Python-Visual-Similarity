All images are drawn without replacement from the Oxford Flower dataset
(`train` split, seed 0), with a disjoint image subset per
experiment. Thread budget: `PYVISIM_NUM_THREADS=4` (the compiled
SSD kernel's OpenMP team size); every runtime is the wall-clock time of one
full scoring call (7 timed calls after one warm-up).

### PSNR

Baseline: **scikit-image 0.26.0 — skimage.metrics.peak_signal_noise_ratio(data_range=255)**.

#### Accuracy

Each image (native resolution) is scored against a copy distorted with
Gaussian noise (std 15); the error is the absolute difference

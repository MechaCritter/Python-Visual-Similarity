CLIPEncoder
===========

The CLIP encoder embeds images with a pretrained
`open_clip <https://github.com/mlfoundations/open_clip>`_ model instead of
aggregating local descriptors. It requires the ``nn`` extra
(``pip install "pyvisim[nn]"``).
